# Deployment

This folder is a zero-build static pilot.

## Current pilot
Open `index.html` directly in a browser.

## Public hosting
Use this folder as the project/root directory on a static host such as Vercel.

## Production boundary
The pilot uses browser-local storage and does not include production authentication, PostgreSQL, object storage, billing, or live OpenAI API calls. These must be connected before a paid production launch.
