# What It Is / What It Ought to Be — International Pilot Instance

## Purpose
A rapid, runnable pilot of the Contract Intelligence product inside the current ChatGPT working environment.

## Run
Open `index.html` in a modern browser. No installation is required.

## Included now
- International market selector; Saudi Arabia included
- Organization settings
- Project register
- Contract register
- Document metadata intake
- 10-field Gap Engine
- Gap review/edit/view
- Actions, owners, deadlines, status
- Executive dashboard
- Contract Diagnostic report
- Browser-local persistence via localStorage

## Intentionally not connected in this rapid pilot
- OpenAI API / automated document analysis
- Cloud authentication and multi-user tenancy
- PostgreSQL / object storage
- Payment processing
- Email/Outlook/SharePoint/Primavera
- Production audit/event infrastructure

Those remain in the production backlog and are not falsely simulated here.

## Product principle
WHAT IT IS → WHAT IT OUGHT TO BE → WHY → EVIDENCE → GAP → IMPACT → ACTION → OWNER → DEADLINE → STATUS
