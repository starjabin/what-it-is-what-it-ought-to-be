# Cross-platform product acceptance matrix
This is an implementation record and acceptance plan, not certification.
- All legacy authenticated routes using AppShell inherit common tokens, desktop/mobile navigation, footer and bilingual navigation. Table semantics and status feedback migrated where applicable; preserve original business logic. Loading/error boundaries added. Full Arabic contract form text, translations of legal content, authenticated workflows, and API/schema migration remain distinct release work.
- Graph Studio: explicit English/Arabic UI dictionary, correct scoped lang/dir, numeric and UTC Gregorian formatting, local persistence, no translation of evidence. Legacy English content is labelled and scoped to English/LTR.
- CI runs Chromium via native DevTools protocol against local built app with no real credentials: home, sign-in, sign-up and graph at 320/375/768/1024/1440; document width, headings, input names, actual mock form submission/filter, locale persistence and RTL. No provider or cloud mutation. Outputs local lab LCP and CLS samples, not field 75th percentile. The UI mock is not a real database test; separate PostgreSQL CI verifies transactions.
- Remaining acceptance: real authenticated routes under two staging tenants, full WCAG 2.2 AA manual screen-reader/keyboard/contrast/zoom tests, full Firefox/WebKit and physical devices, production-like LCP/INP/CLS field instrumentation, Arabic content QA and legal terminology review, all backend routes server authorization and stable contracts. Do not mark these as passed without actual evidence.
- F-001 real tenant authentication and full staging schema remain blocking. No production merge.
